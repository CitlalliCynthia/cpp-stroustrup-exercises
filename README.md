# C++ Programming: Principles and Practice — Solutions

This project serves as my personal workspace where I host and document my solutions to the exercises and drills from Bjarne Stroustrup's book, **"Programming: Principles and Practice Using C++"**.

The primary purpose of this repository is to build a rock-solid foundation in Modern C++, master Object-Oriented Programming (OOP) paradigms, and practice writing clean, maintainable, and efficient code.

---

## 🛠️ Some concepts
As I progress through the book, I use this space to study and implement core computer science principles and software architecture design concepts, including:

* **Object-Oriented Design:** Custom type architecture using `class` and `struct`, data encapsulation, managing private members, and strictly enforcing class invariants.
* **Const Correctness:** Safeguarding system state and memory layout through consistent usage of `const` qualified functions, members, and references.
* **Operator Overloading:** Customizing standard operations (`+`, `-`, `*`, `==`, `<<`, `>>`) to integrate user-defined types seamlessly into standard C++ streams.
* **Function & Memory Mechanics:** Managing variable scope, lifetimes, and storage duration, alongside efficient parameter passing mechanics (by value, by reference, and by const reference).
* **Code Organization:** Mastering physical file structure by separating declarations into header files (`*.h`) and implementation details into source files (`*.cpp`), while using namespaces to prevent naming collisions.
* **Resource Management & Robustness:** Defending program execution flows through input validation, data tokenization, custom domain exceptions, and structured error handling.

---

## 📂 Repository Organization
The workspace is organized logically by chapters. Inside each chapter folder, you will find independent exercises packaged with their respective interface definitions and test environments:

* `Chapter_XX/` — Represents a complete study block from the textbook.
  * `Exercise_YY_Title/` — Dedicated workspace for a specific problem statement.
    * `*.h` — Class layout and function signatures (interfaces).
    * `*.cpp` — Actual logic and algorithmic implementation.
    * `main.cpp` — Isolated testing simulation script to verify edge cases and features.
